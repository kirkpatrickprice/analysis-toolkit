# KirkpatrickPrice Documentation Assets

This directory contains branding assets for the KP Analysis Toolkit documentation.

## Files

- **kp-logo.svg**: KirkpatrickPrice logo for documentation header
- **custom.css**: Custom CSS styling following KP brand guidelines

## Brand Guidelines

### Colors
- **Primary Blue**: #1976d2 (KP brand blue)
- **Light Blue**: #42a5f5 (accent color)
- **Dark Blue**: #0d47a1 (darker shade for contrast)
- **Gray**: #37474f (professional gray)

### Typography
- **Primary Font**: Roboto (clean, professional)
- **Code Font**: Roboto Mono (monospace for code blocks)

## Logo Usage

The KP logo is used in the documentation header and as favicon. The current logo is a placeholder SVG that can be replaced with the official KirkpatrickPrice logo when available.

### Replacing the Logo
To use the official KP logo:
1. Replace `kp-logo.svg` with the official logo file
2. Update the file extension in `mkdocs.yml` if needed (e.g., `.png`, `.svg`)
3. Ensure the logo works well on both light and dark backgrounds

## Customization

The CSS file includes:
- KP brand colors
- Professional styling for tables, code blocks, and navigation
- PowerShell-specific syntax highlighting
- Responsive design elements
- Dark/light mode support

All customizations maintain accessibility and readability while reflecting the professional KirkpatrickPrice brand identity.
